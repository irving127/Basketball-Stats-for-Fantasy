How scoring works

Fantasy points per game are calculated from the player's real 2025-26 per-game stats with this site scoring system, a simplified version of common fantasy points formats: PTS 1 point each, REB 1.2, AST 1.5, STL 3, BLK 3, TOV minus 1. Salary is set from fantasy points, so the cap forces real choices. Roster: one PG, SG, SF, PF, and C, plus one FLEX who can be any position. Position eligibility is site-defined and includes common secondary positions. Worked example, the league's fantasy cheat code: Nikola Jokić scores 27.7 pts + 12.9 reb x 1.2 + 10.7 ast x 1.5 + 1.4 stl x 3 + 0.8 blk x 3, minus 3.7 turnovers, for 62.1 fantasy points a game. He also costs $23 of your $110, which is the whole game.
